# 金融资讯深度分析助手

基于大模型API的金融资讯结构化分析工具。输入一篇金融资讯，AI自动判断资讯类型，输出包含核心事实、深度分析、投资启示和情绪判断的专业分析报告。

## 功能特点

- **智能分类**：自动识别资讯类型（宏观政策 / 行业动态 / 公司微观 / 市场事件）
- **自适应分析框架**：根据资讯类型切换分析重点，不硬套模板
  - 宏观政策：政策传导、流动性影响、行业轮动
  - 行业动态：供需变化、竞争格局、受益环节
  - 公司微观：基本面、财务影响、估值、同业对比
  - 市场事件：诱因、资金行为、情绪持续性
- **结构化输出**：一句话总结 / 核心事实 / 深度分析 / 投资启示 / 情绪判断
- **区分事实与观点**：事实标注来源，观点给出推理逻辑
- **机会与风险并重**：不做单边推荐，同时提示受益方向和风险点
- **支持网页端使用**：基于Streamlit，手机浏览器打开即可使用

## 技术栈

- Python 3.10+
- requests（HTTP请求）
- Streamlit（Web界面）
- 硅基流动API（DeepSeek-V3大模型）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置API Key

修改 `config.py` 中的 `API_KEY` 为你的硅基流动API Key。

### 3. 命令行方式运行

```bash
# 交互式输入
python main.py

# 从文件读取
python main.py article.txt
```

### 4. 网页方式运行

```bash
streamlit run app.py
```

浏览器打开 `http://localhost:8501` 即可使用。

## 核心设计思路

### 自适应Prompt设计

传统的摘要工具对所有资讯使用同一套模板，导致微观新闻硬套宏观框架。本项目让大模型先判断资讯类型，再采用对应的分析框架：

```
资讯输入 → 类型判断 → 对应分析框架 → 结构化输出
```

### Prompt Engineering要点

- **角色设定**：10年经验资深金融分析师，建立专业人设
- **输出约束**：区分事实与观点、数据意识、机会风险并重
- **格式控制**：固定板块结构，便于后续程序化处理
- **温度参数**：temperature=0.3，保证输出稳定性

## 部署

### 本地局域网使用

手机和电脑连同一WiFi，运行 `streamlit run app.py`，手机浏览器访问终端显示的Network URL。

### 公网部署（免费）

1. 代码上传GitHub
2. 登录 [Streamlit Community Cloud](https://share.streamlit.io)
3. 关联GitHub仓库，设置API Key为Secrets
4. 部署完成后获得公网链接，手机随时随地可用
